O SAE(Sistematização da Assistência da Enfermagem) é um sistema de apoio ao trabalho da equipe de enfermagem. Ele foi pensado para resolver os problemas dos dados clínicos de papel, reduzir erros e melhorar o atendimento aos pacientes. 
#Funcionalidades
--> Gestão de pacientes
--> Plano de cuidados
--> Controle de acesso
--> Tecnologia PWA
--> Serviço powerSync
# Tecnologias empregadas
--> Html
--> CSS
--> JavaScript
--> NodeJS
-->Mysql
O Sistema ainda está em desenvolvimento e vai ser divido em módulos futuramente.
