# SAE-Sistematização da assistência de Enfermagem

O SAE(Sistematização da Assistência da Enfermagem) é um sistema web de apoio ao trabalho da equipe de enfermagem. Ele foi pensado para resolver os problemas dos dados clínicos de papel, reduzir erros de dados, melhorar o atendimento aos pacientes e facilitar a comunicação entre os profissionais. 

## Funcionalidades

** Gestão de pacientes:** Cadastro e consulta de pacientes
** Plano de cuidados:** Plano de tratamento definido pelo enfermeiro bem como o acompanhamento clínico da equipe
** Controle de acesso:** Perfis de acesso com a respectiva permissão operacional
** Tecnologia PWA:** Instalação do sistema como App nativo a diferentes sistemas operacionais(Windows, Linux, Android e IOS)
** Serviço PowerSync:** Sincronização dos dados locais com o banco de dados na nuvem

## Tecnologias empregadas

**Front-end:** HTML5, CSS3, JavaScript(PWA)
**Back-end:** Node.js, Sincronização

**Status do projeto:** O Sistema ainda está em desenvolvimento e vai ser divido em módulos futuramente.
